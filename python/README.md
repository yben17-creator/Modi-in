# Earnings Value Intelligence (EVI) — שלב 3

מערכת לסינון מניות טכנולוגיה בארה"ב לקראת דוחות רבעוניים, על בסיס **נתונים אמיתיים**:
SEC EDGAR לדוחות הכספיים, להגשות, ל-Form 4 ולהנפקות, ו-Finnhub (אופציונלי) למחירים, ללוח הדוחות, לקונצנזוס ולחדשות.

**עיקרון מנחה:** נתון שלא התקבל מספק מוצג כ**חסר**. הוא לעולם אינו מוחלף בנתון הדגמה, בממוצע או באפס.

---

## 1. התקנה (פעם אחת)

דרוש Python 3.10 ומעלה (בדוק עם `python --version`).

```bash
# 1. פתח טרמינל בתיקיית הפרויקט (evi-app)
cd evi-app

# 2. צור סביבה וירטואלית
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS / Linux:
source .venv/bin/activate

# 3. התקן את החבילות
pip install -r requirements.txt
```

## 2. הגדרת מפתחות (`.env`)

העתק את `.env.example` לקובץ חדש בשם `.env` וערוך אותו:

| משתנה | חובה? | מה הוא מפעיל |
|---|---|---|
| `SEC_USER_AGENT` | **חובה** | גישה ל-SEC EDGAR. SEC דורש שם וכתובת דוא"ל, לדוגמה `"Yossi Cohen yossi@example.com"`. אין צורך במפתח. |
| `FINNHUB_API_KEY` | מומלץ | מחיר עדכני, טווח 52 שבועות, לוח דוחות עם קונצנזוס, הפתעות EPS, המלצות אנליסטים וחדשות. מפתח חינמי ב-finnhub.io. |
| `MASSIVE_API_KEY` | אופציונלי | היסטוריית מחירים יומית (לשעבר Polygon.io) ל-Backtest ולמומנטום. massive.com. |
| `ENABLE_YFINANCE` | אופציונלי | `true` מפעיל היסטוריית מחירים מ-Yahoo דרך הספרייה הלא-רשמית yfinance (`pip install yfinance`). כבוי כברירת מחדל. |
| `TELEGRAM_*`, `SMTP_*` | אופציונלי | שליחת התראות מסריקות מתוזמנות. |

**מה עובד עם אילו מפתחות:**

- **רק `SEC_USER_AGENT`:** דוחות כספיים, יחסים, ציון בריאות, דגלים אדומים, Form 4, דילול ותאריכי דוח משוערים. אין מחיר, ולכן התמחור, ה-DCF למניה, חלונות הכניסה והמומנטום יוצגו כחסרים.
- **+ Finnhub:** מחיר, שווי שוק, DCF למניה, לוח דוחות אמיתי, קונצנזוס, הפתעות EPS וחדשות.
- **+ Massive או yfinance:** בדיקות היסטוריות לחלונות כניסה ויציאה, מכפילים היסטוריים, Momentum Monitor ואימות Walk-Forward.

## 3. הפעלה

```bash
streamlit run app.py
```

הדפדפן ייפתח בכתובת `http://localhost:8501`.

**זרימת עבודה:**

1. בסרגל הצד בחר חלון ימים (ברירת מחדל: 7 עד 30) וסקטורים, ולחץ **"הרץ סריקה"**.
2. **מצב הסריקה:**
   - עם מפתח Finnhub, המערכת סורקת את כל לוח הדוחות ומסננת לפי בורסה (NASDAQ/NYSE) וסקטור.
   - בלי מפתח, היא סורקת את המניות שב-`data/universe.csv` (אפשר לערוך את הקובץ).
3. הסריקה הראשונה איטית, כי היא מורידה את הנתונים מ-SEC. מנתונים במטמון מקומי (`data/evi.sqlite`), כך שהסריקות הבאות מהירות.
4. לחיצה על שורה בטבלה בוחרת חברה. במסך **"דוח מחקר"** תמצא את הסקירה המלאה, את מודל ה-DCF האינטראקטיבי ואת כפתורי הייצוא ל-PDF, HTML ו-Excel.
5. **"טען חברה בודדת"** בסרגל הצד מאפשר לחקור כל טיקר, גם אם הוא מחוץ לחלון הזמן.

## 4. סריקות מתוזמנות והתראות (Phase 6)

```bash
python -m evi.monitor.scan                 # לפי ברירות המחדל ב-config.yaml
python -m evi.monitor.scan --min 7 --max 21 --sectors "Cybersecurity,Semiconductors"
```

הסקריפט סורק את השוק ואת כל חברות רשימת המעקב, ושומר צילום של הציונים. הוא מתריע כשמתרחש אחד מאלה:

- ציון משתנה ב-10 נקודות או יותר.
- הסיווג משתנה.
- מופיע דגל חדש בחומרה גבוהה.
- מופיעה התראת מומנטום.

ההתראות נשלחות ל-Telegram או לדוא"ל, אם הוגדרו, ומוצגות במסך רשימת המעקב.

**תזמון יומי:**

- **Windows (Task Scheduler):** צור משימה שמריצה את `C:\path\evi-app\.venv\Scripts\python.exe -m evi.monitor.scan` כאשר "Start in" מוגדר ל-`C:\path\evi-app`.
- **macOS / Linux (cron):** `30 7 * * 1-5 cd /path/evi-app && .venv/bin/python -m evi.monitor.scan >> data/scan.log 2>&1`

צילומי הקונצנזוס נשמרים בכל סריקה. אחרי 30 יום של סריקות המערכת מתחילה להציג **כיוון עדכוני אנליסטים**, נתון שאינו זמין בחינם בשום API.

## 6. איך נתונים חסרים מטופלים

- **תג XBRL לא נמצא:** הערך "חסר", עם הסבר.
- **ציונים:** רכיב חסר מוצא מהציון והמשקל מנורמל. ציון הבריאות מחושב רק מעל 60% כיסוי נתונים, וציון ההזדמנות מעל 50%. חברה ללא ציון בריאות או ציון תמחור מסווגת **"לא ניתן להעריך — נתונים חסרים"**.
- **השוואה לעמיתים:** מתבצעת רק מול חברות שנסרקו בפועל באותו סקטור (לפחות 3). אין חציונים חיצוניים או קבועים.
- **תאריכי דוח:** מסומנים כ-"לפי ספק (לא אומת)" כשהם מגיעים מ-Finnhub, כ-"משוער (חישוב מקומי)" כשהם מחושבים מהיסטוריית 8-K, וכ-"מאושר" רק אחרי שאישרת ידנית בדוח המחקר.
- **החריג היחיד, מסומן בהערה:** כשחברה מדווחת מזומן אבל אין לה תג של השקעות קצרות או של חוב, אלה נחשבים 0. זו פרקטיקת הדיווח המקובלת: רכיב שאינו קיים לא מתויג.

## 7. מגבלות ידועות

- **סיווג סקטורים:** קודי SIC של SEC גסים, ולכן סייבר ו-AI מזוהים רק דרך `sector_overrides.csv`, שאותו אפשר להרחיב.
- **תחזיות הנהלה:** אינן זמינות כנתון מובנה בחינם, ולכן הן מוזנות ידנית ומסומנות כהזנה ידנית.
- **היסטוריית הפתעות EPS:** בתוכנית החינמית של Finnhub יש כ-4 רבעונים בלבד, והמערכת מסמנת "ניתוח חלקי". ההפתעה בהכנסות אינה זמינה בחינם.
- **Backtest:**
  - כולל רק חברות הנסחרות היום (Survivorship bias, מוצג במסך האימות).
  - הציונים הפונדמנטליים אינם משוחזרים Point-in-Time, ולכן אינם נבדקים.
- **דגלי חדשות:** מזוהים לפי מילות מפתח ומסומנים "דיווח תקשורתי". זו טענה ולא עובדה.
- **משקלות וספים:** כל המשקלות והספים הם הנחות עבודה, וניתן לשנות אותם ב-`config.yaml`.
